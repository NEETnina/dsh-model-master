DSH Model Picker · dsh-model-master

A Spotlight-style model selector for DeepSeek Harness (DSH) — search across providers, measure models with a real streaming request, and compare against a global leaderboard.

GitHub npm 中文

Install in 30 seconds

dsh plugin --profile web add dsh-model-master

Restart DSH afterwards (or let HMR reload it). Requires DSH and Node.js ≥ 20. No runtime dependencies, no build step.

What it adds

  1. Find faster — global search, provider grouping, and a ⚡ smart pick that locks onto the best model in the current scope.
  2. See the speed — real streaming probes measured server-side: TTFT (time to first token) and TPS (tokens per second).
  3. Get a reference — a global TOP100 leaderboard built from Artificial Analysis indices and Design Arena Elo.

No fabricated numbers

  • Probes run on the host and time themselves; the browser never computes a number.
  • A failed probe reports the failure (timeout / unreachable / 403 / quota / no key) — never an invented TPS.
  • The leaderboard only contains models with real benchmark fields; when the source is unreachable it shows the cached snapshot marked offline.

Privacy

  • No telemetry, no reporting, no tracking.
  • The plugin never reads, stores or logs your API keys.
  • Every local HTTP route is loopback-fenced (localhost / 127.0.0.1 / ::1 plus an Origin check).
