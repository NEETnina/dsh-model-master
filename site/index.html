DSH 模型选择器 · dsh-model-master

DeepSeek Harness（DSH）的模型选择器 / 模型选择大师：把原生那个狭小的模型下拉列表， 接管成一块可搜索、可测速、可对照全球榜单的居中大面板。

GitHub 仓库 npm 包 English

30 秒安装

dsh plugin --profile web add dsh-model-master

装完重启 DSH（或等 HMR 自行重载）。需要 DSH 与 Node.js ≥ 20；插件零运行时依赖、无构建步骤。 也可以从源码装：git clone 之后 dsh plugin --profile web add .。

它解决什么问题

DSH 原生的模型选择器是一份紧凑的下拉列表：模型一多就难找，看不出哪个快，也没有任何"这个模型到底行不行"的客观参照。这个插件补齐三件事：

  1. 找得快 —— 全局搜索、按渠道分组、以及「⚡ 智能优选」直接给出当前分组里综合最优的那个。
  2. 看得见快 —— 对任意模型发起真实流式请求，测出 TTFT（首字延迟，ms）与 TPS（生成吞吐，tok/s）。
  3. 有参照 —— 全球 TOP100 榜单，数据来自 Artificial Analysis 智能指数与 Design Arena Elo。

真实测速：TTFT 与 TPS

  • 服务端发起流式请求并自己计时，浏览器不参与任何数字计算。
  • ×1 快速 / ×3 稳定（取中位数），把单次测速约 17–22% 的随机波动压下去。
  • 批量测速逐个进行（并发 2，单条超时上限 20s），可随时停止。
  • 失败就是失败：区分超时 / 不可达 / 403 / 配额 / 无密钥，绝不伪造一个看起来还行的 TPS。
  • 测速会把推理档位显式钉在最低一档，避免"测得的是档位的速度，而不是模型的速度"。

全球 TOP100 榜单

最多 100 行，按 Artificial Analysis 智能指数排序，辅以代码 / Agent 指数与 Design Arena Elo。 点任意行会跳到本机搜索同名渠道，由你自己挑渠道（不做自动匹配，避免把榜单的模型错配到本地的另一个渠道）。 每日自动同步，离线时展示本地缓存并明确标注。

数据与隐私

  • 不收集任何遥测；不上报；不追踪。
  • 插件本身不接触、不存储、不打印任何 API Key。
  • 所有本地 HTTP 路由都有 loopback 围栏：只接受 localhost / 127.0.0.1 / ::1 的 Host，并校验 Origin。
  • 对外请求只有两处：榜单数据源与版本检查。

常见问题

怎么安装？
见上面的「30 秒安装」——一条 dsh plugin 命令。
测速的数字可信吗？
是真实流式请求的实测值；测不出来就显示失败原因，不会编造。
榜单数据从哪来？
OpenRouter 模型目录里的 Artificial Analysis 指数与 Design Arena Elo。
支持哪些界面语言？
15 种：英文 / 中文 / 印地语 / 西班牙语 / 法语 / 阿拉伯语 / 孟加拉语 / 葡萄牙语 / 俄语 / 乌尔都语 / 印尼语 / 德语 / 日语 / 韩语 / 土耳其语（阿拉伯语与乌尔都语自动 RTL）。
